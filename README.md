# Babaluum web

The Babaluum site: Next.js 16 (App Router), TypeScript, SCSS modules, Lenis smooth scroll and Framer Motion. No Tailwind.

```bash
npm install
npm run dev        # http://localhost:3000
npm run check      # typecheck + eslint + stylelint + tests
npm run build
```

## Architecture

Folders are layers. Each layer may only import from the layers below it, and ESLint enforces this (`eslint.config.mjs`).

```
src/
  app/                 routes only: compose sections, nothing else
  components/
    sections/          page sections (HomeHero, ProgramsGrid, CtaBanner, …) + cast/
    layout/            Header, Footer
    cards/             ProgramCard, StatCard, ProjectCard, PostCard, MemberCard, ReviewCard
    playground/        physics stage that binds the world to the DOM
    characters/        SVG rigs (Robot, Alien, Globe), Artifact, Sticker
    motion/            Reveal, Parallax, SplitWords, Magnetic
    primitives/        Button, Heading, NotchedSurface, Media, Accordion, Icon, …
  content/             all copy and image references (Spanish)
  hooks/               the only place (with providers/) allowed to use effects
  providers/           SmoothScroll (Lenis + MotionConfig)
  domain/              pure TypeScript: physics, NPC behaviors, rig pose. No React.
  styles/              tokens (colors, type, spacing, motion) + mixins
```

Each component is a folder: `Name.tsx`, `Name.module.scss`, `index.ts`.

## Guardrails

These are checks, not conventions:

| Rule | Enforced by |
| --- | --- |
| Layer boundaries (e.g. primitives can't import content, routes can't import primitives) | `no-restricted-imports` per folder |
| `useEffect`/`useLayoutEffect` only in `hooks/` and `providers/` | `no-restricted-imports` |
| No `setTimeout`/`setInterval` in components | `no-restricted-globals` |
| No comments (fix the root cause, or encode it as a check) | `tooling/eslint-rules/no-comments.js` |
| A component imports only its own `.module.scss` | `tooling/eslint-rules/scss-module-name.js` |
| No hex colors outside `styles/tokens` and `palette.ts` files | ESLint + Stylelint |
| No enums, no default exports outside routes, no non-null `!` | ESLint |
| Small functions: max 3 params, complexity 10, 90 lines | ESLint |
| z-index from tokens, no `transition: all`, no `!important` | Stylelint |

## The cast: characters and physics

The robot, alien and globe are rebuilt as layered SVG rigs, so every part (head, eyes, antennae, arms, continents) can move on its own. They are NPCs in a small 2D physics world (`src/domain/physics`):

- **NPCs** look at the cursor, lean with their velocity, blink, and smile wider when excited. Roamers (alien, globe) wander between artifacts and bump them. Anchored NPCs (the hero robot, the CTA globe) stay in a slot in the headline and lean out toward the cursor.
- **Artifacts** (stars, crowns, plus signs, asterisks, pills, the sticker) are light bodies. When an NPC hits one, it gets pushed, spins, and glows from the collision energy, then drifts back home. They also flee the cursor. Click or tap to poke everything nearby.
- NPCs never collide with each other, only with artifacts.
- `castScaleFor(width)` scales both the drawings and their collision radii on small screens.
- With `prefers-reduced-motion`, the world settles at rest and Lenis is off.

To add a character: draw it in `components/characters/`, take `pose: PoseValues`, and add a factory in `sections/cast/cast.tsx`.

## Notched shapes

The ticket-style cutouts from the design are CSS masks generated by `NotchedSurface/notchMask.ts` (tested). Use a preset (`NOTCHES.ticket`, `tab`, `side`, `photo`, `portrait`, `banner`, `stat`) or pass your own `{ edge, at, kind, mirror }` list.

## Content status

Copy is written in Spanish from the Babaluum homepage design. The inner pages adapted the template's English placeholder text, so treat programs, plans, prices, team names, testimonials, projects, blog posts and legal text as **placeholders to replace**. Photos were extracted from the design files.
